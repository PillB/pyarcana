### S11-F02 — The learner believes changing dict to dataclass automatically validates runtime types and required semantic values.
- **Category:** FALSE_CORE_MENTAL_MODEL
- **Location:** opening + S11-T1-A
- **Evidence:** The lesson says a named type has fixed boxes whose required fields cannot be left empty and prevents one field being text in one function and numeric in another. The first dataclass does not enforce type hints or non-empty values at runtime.
- **Impact:** The learner believes changing dict to dataclass automatically validates runtime types and required semantic values.
- **Proposed fix:** Separate named structure, static annotations and runtime validation; state that dataclass/type hints alone do not enforce domain validity.
