## S48-F06 — P1 — Vector comparison silently accepts incompatible dimensions and zero vectors.

**Verdict:** CONFIRMED_FINDING: the lab should teach the invariant before computing similarity.  
**Improved version:** Reject unequal dimensions, non-finite values and zero-norm cosine inputs with a distinct `INVALID_EMBEDDING_VECTOR` result.  
**Reasoning:** Shape/norm validation is prerequisite evidence for vector similarity.
