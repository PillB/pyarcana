## Method, evidence and coverage

Read the repo `AGENTS.md`, lesson-specific instructions, source and tests; traversed the deployed desktop site and its `#basics` five-stage navigation; compared source versus live pixels and interaction semantics. Independently read-only QA challenged fixes and found a real tab-switch draft loss and a shared editor keyboard trap. Source inventory: **8 subtopics, 8 I Do demonstrations, 24 We Do exercises, 11 self-check questions, 4 two-task formative topic evaluations and one You Do application task**. The course totals remain **52 sections, 416 demos and 1,248 We Do exercises**.

Scope matters. The desktop capture and selected interaction probes do **not** establish all 24 live exercises' end-to-end correctness, all four-choice permutations (4¹¹ = **4,194,304** complete answer vectors), mobile/zoom equivalence, server logs, or a measured animation frame sequence. The new code is **not on the deployed URL**. This review applied five distinct *source-analysis lenses*, five *source-level adversarial lenses* and four *visual/accessibility lenses*, not five fully executed independent browser trials per card. No six-per-card end-to-end execution was performed. A green code-level oracle is not a rendered or back-end oracle.

## Every We Do card: scan order and falsifiable learning contract

**Per-card controls** have the same layout: number/title, preamble, instructions, starter `Copy`, kind, optional hint group, S02-only Python editor button, `Run`, `Reset`, solution reveal/hide with expected output and feedback. E1 hints stay visible; E2/E3 hints are native collapsed `<details>` until opened. Tabs and code runner have separate mounting/animation state. Every solution reveal is a *model answer*, not proof the learner tried it. The rows below describe independent expected-versus-wrong oracles, not a claim that every card was executed six times.

| Subtopic / exercise | Authored goal; correct result | Deliberately wrong or edge-case attack |
|---|---|---|
| **T1-A E1** | Classify five literals; outputs `int, float, str, bool, NoneType` in order | Confuse `None` with `str` or `null`; silently coerce input first |
| T1-A E2 | Show `42 == "42"` false; conversion equality true; `isinstance(True,int)` true | Teach implicit cross-type equality or use `True` as money |
| T1-A E3 | Model six intake fields; phone `str`, age `int`, active `bool`, six assertions true | Coerce telephone to int, lose zero prefixes or use real PII |
| **T1-B E1** | `strip` and `int` turn spaced age into `21 int` | Claim `strip` guarantees numeric validity; try `int("abc")` |

## Root causes, release tiers, trade-offs and next gates

1. **P0 / truthfulness and release evidence:** do not call a manual 'Práctica completada' stage an assessed exercise pass; separate *viewed*, *attempted*, *self-reported* and *machine-verified* in product wording and data model before a verified-mastery claim. No backend grades or logs were inspected. Run exact-SHA browser and pinned Python gates; test deployment parity before public production declaration.
2. **P1 / subject correctness:** code and diagrams must encode business and language semantics; data type decisions, False/0 identity, Decimal exponent and rounding boundaries need independently derived counterexamples. The 17 S02 contract checks include two mutation-style falsifiable checks and exact terminal stdin variants.
3. **P1 / prerequisite graph:** model first introduction separately from deep competency. S02 previews `dict` vocabulary needed by S04/S05; S06 teaches dictionary operation. Assess only knowledge taught *up to* S02; defer functions, branches and exception recovery.
4. **P1 / shared runtime:** S02 pilot is lazy, Python-only and network-dependent. Since all editors share Pyodide, queue/worker isolation remains a **risk hypothesis**, not a confirmed race. Prove output ownership under close/reopen and concurrent run before wide rollout. Tab now navigates naturally instead of indenting; keyboard users use spaces, an explicit UX compromise.
   **Failed fix hypothesis → researched correction:** a stable `useRef(Map)` at the SectionView level did preserve drafts functionally, but React's lint gate rejected reading `.current` during JSX render. [React's own reference](https://react.dev/reference/react/useRef#caveats) warns against this; replacing it with immutable `useState` keyed drafts respects render purity. This can cause parent rerendering per keystroke, a performance trade-off that requires browser profiling rather than an untested optimization.
5. **P2 / visual path:** redesign orientation for 24 cards only after responsive captures and keyboard/zoom traces. Retain useful hints but avoid immediate accidental solution exposure. The patch limits hint disclosure changes to S02; all other sections keep existing contracts.
6. **Test discipline:** keep `npm run lint:complexity` at ceiling 15 with monotonic legacy-debt reduction (WeDoTab debt reduced, 32→31 registered offenders). Run falsifiable negative controls, no tautological click-only assertions. Revert generated timestamp-only reports before committing so an adversarial runner can correctly detect *new* file writes.
   **Stacked-PR CI trap:** the first S02 draft PR had no workflow run because the job only triggered for PRs based on `main` or `curriculum/55`. A follow-up explicitly includes the exact S01 review branch in the pull-request filter. A regression test now proves that the S02 browser spec is both present *and triggerable* for this particular stacked review. It is not a substitute for observing the actual workflow result.

**Verified locally so far:** S02 Python contracts, TypeScript, source structural/course-completeness checks, glossary/first-use/contrast UX gates and complexity gate; Node/Python adversarial results are recorded separately in the final run log. **Blocked/not yet run:** local Chromium E2E (download artifact invalid); pinned `.venv-content` strict Python audit (environment drift); executed 24×6 live learner attempts; all quiz permutations; mobile, 400% zoom, assistive-tech trace, real backend events and exact deployed SHA.
