# Accessibility Validation Matrix

## WCAG 2.2 AA conformance

| Criterion | Status |
|---|---|
| Keyboard operation | All buttons/dialogs reachable via Tab |
| Non-colour-only encoding | Status pills use text + icon |
| 200% zoom reflow | No horizontal scroll |
| Screen-reader labels | aria-label on icon buttons |
| Data-table fallback | Dependency graph has table view |
| Focus visible | focus-ring utility |
| Touch targets | Minimum 24px CSS |

All 13 capstones have ACCESSIBILITY.md documenting keyboard, non-colour-only, and readable output requirements.
