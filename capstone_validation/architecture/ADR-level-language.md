# ADR — Curricular Level Language (non-inflated)
**Status:** Accepted · **Date:** 2026-07-29

Forbidden learner-facing terms: experto · máster · master · senior · senior-ready ·
job-ready · listo para aplicar. Approved names: L1 Fundamentos Guiados, L2 Práctica
Aplicada Independiente, L3 Integración y Evaluación Avanzada, L4 Sistemas de
Producción Gobernados. Required qualification shown in UI + legal pages: "Estos son
niveles de competencia curricular de PyArcana... no establecen por sí mismos
antigüedad laboral, licencia profesional, nivel de empleo ni certificación externa."

Phase numeric `id` (0–3) preserved → saved progress keys unchanged. Badge IDs
unchanged. Historical completion preserved under prior version; new evidence required
for upgraded version (no fabricated retrospective evidence).
