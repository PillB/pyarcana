## Regeneration

```sh
bun run scripts/mirror.mjs
```

The script writes the JSON artefacts; the Markdown artefacts are hand-authored
and updated only when the spec or the TS modules change. The script's stdout
reports the mirrored counts (13 capstones, 52 sections, 4 levels, 13 badges,
12 final interfaces, 13 rubrics) so a reviewer can confirm the mirror matches
the canonical counts at a glance.
