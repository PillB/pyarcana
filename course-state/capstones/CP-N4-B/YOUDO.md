# You Do (Haces tú)

Trabajo independiente.

1) Agrega SLO (esto es, un objetivo de nivel de servicio: la promesa medible de qué tan disponible o rápido debe estar el sistema). 2) Agrega consistencia train/serve. 3) Agrega registros de incidentes.

## Criterios de éxito
- El código corre desde un entorno limpio.
- Los tests normal/boundary/failure pasan.
- No hay PII real ni secretos.
- Las limitaciones están documentadas.
