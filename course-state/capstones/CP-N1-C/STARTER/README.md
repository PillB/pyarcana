# CP-N1-C — por dónde empezar

Tu archivo es `cp_n1_c.py`, en esta carpeta. Ya tiene las funciones declaradas: escribe el cuerpo
de cada una según `../BRIEF.md`, en el orden de las reglas (identidad, relación, decisión, cola,
producto, paquete y corrección). Si hiciste el You Do de S13, puedes partir de tu
`demo_n1_dashboard.py`.

Verifica con `python3 tests/test_demo.py` desde la raíz del paquete. Las pruebas revisan tu
archivo, no la referencia: al principio fallan todas, y cada fallo dice qué función escribir.

La solución de referencia está en `../reference/cp_n1_c.py`. Léela solo para comparar cuando tus
pruebas pasen.
