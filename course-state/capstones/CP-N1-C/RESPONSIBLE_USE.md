# Requisitos de uso responsable

NO infiere automáticamente: parentesco, colusión, fraude, asociación criminal, propiedad beneficiaria, relación causal. Requiere revisión humana. Reporta incertidumbre y falsos positivos (esto es, casos que el sistema marcó como coincidencia pero que un humano revisa y descarta).

## Lo que este proyecto NO hace
- No decide adversamente sobre personas sin revisión humana.
- No infiere automáticamente fraude, parentesco, colusión, asociación criminal, propiedad beneficiaria ni relación causal.
- No sobreinterpreta asociaciones como causalidad.
