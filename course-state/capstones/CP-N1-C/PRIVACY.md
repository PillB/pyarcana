# Requisitos de privacidad

Hoja de privacidad obligatoria. Mecanismo de corrección. proveniencia (esto es, de dónde viene cada dato: qué archivo, qué fuente, qué fecha) de cada señal.

- Solo datos sintéticos (example.test).
- No se recopila PII real.
- Proveniencia y mecanismo de corrección cuando aplica.
