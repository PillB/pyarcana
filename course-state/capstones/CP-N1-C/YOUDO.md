# You Do (Haces tú)

Trabajo independiente.

1) Agrega geofencing (esto es, cercas geográficas: reglas que comparan si dos puntos están dentro de una zona, sin afirmar que las personas se conocen) como señal. 2) Agrega un análisis de falsos positivos (esto es, casos que el sistema marcó como coincidencia pero que un humano revisa y descarta). 3) Documenta qué NO infiere el tablero.

## Criterios de éxito
- El código corre desde un entorno limpio.
- Los tests normal/boundary/failure pasan.
- No hay PII real ni secretos.
- Las limitaciones están documentadas.
