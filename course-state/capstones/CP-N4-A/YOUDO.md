# You Do (Haces tú)

Trabajo independiente.

1) Agrega el Dockerfile non-root (esto es, ejecutar el proceso con un usuario sin privilegios). 2) Agrega migraciones. 3) Agrega backup y recovery.

## Criterios de éxito
- El código corre desde un entorno limpio.
- Los tests normal/boundary/failure pasan.
- No hay PII real ni secretos.
- Las limitaciones están documentadas.
