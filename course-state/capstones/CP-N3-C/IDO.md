# I Do (Yo demuestro)

El instructor modela el proceso paso a paso en voz alta.

1) Mostrar el baseline (esto es, una línea base: el resultado más simple y determinista contra el que se compara todo lo demás). 2) Mostrar la calibración (esto es, verificar que los puntajes del modelo correspondan a probabilidades reales). 3) Mostrar la abstención (esto es, que el modelo diga 'no sé' en vez de adivinar cuando no está seguro).
