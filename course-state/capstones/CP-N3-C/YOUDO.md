# You Do (Haces tú)

Trabajo independiente.

1) Agrega medición por subgrupo. 2) Agrega monitoreo de drift (esto es, deriva: cuando los datos reales cambian con el tiempo y el modelo envejece). 3) Agrega ruta a revisión humana.

## Criterios de éxito
- El código corre desde un entorno limpio.
- Los tests normal/boundary/failure pasan.
- No hay PII real ni secretos.
- Las limitaciones están documentadas.
