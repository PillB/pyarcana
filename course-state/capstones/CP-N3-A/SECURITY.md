# Requisitos de seguridad

No expone el benchmark (esto es, un conjunto de pruebas etiquetadas para medir qué tan bien funciona un sistema) sin etiquetas gold controladas.

## Controles obligatorios
- No secretos embebidos.
- Entradas validadas.
- Salidas sanitizadas.
- Datos sintéticos o legalmente reutilizables.
