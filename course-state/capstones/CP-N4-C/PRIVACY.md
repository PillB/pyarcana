# PRIVACY — CP-N4-C harness (esto es, un arnés: la estructura que orquesta, limita y observa a los agentes mientras trabajan)

## Data minimisation
- The harness operates exclusively on a **synthetic** knowledge base
  generated by `data/generate.py`. No real customer records, real names,
  real emails, or real identifiers are ingested.
- The default `WebAdapter` returns fictional snippets under
  `*.example.test` domains. No real search engine is queried.

## PII handling
- The `redact()` filter in `tracing.py` scrubs:
  - email addresses (`[email-redacted]`)
  - `Authorization: Bearer …` headers (`[token-redacted]`)
  - `api_key=…` / `token=…` / `secret=…` / `password=…` key/value pairs
  - long opaque tokens (≥ 32 chars), e.g. JWT bodies
- Redaction is applied to every span (esto es, un segmento de una traza: cuánto duró y qué hizo un solo paso) attribute, every tool call record,
  every incidente (esto es, un evento donde el sistema se comportó mal o se cayó, que se debe registrar y analizar) context, and the final answer text before persistence.
- The `send_email` handler replaces the `to` address with the literal
  `[email-redacted]` placeholder when storing it in the trace; the real
  address (if any) lives only in the in-memory outbox used by tests.

## ACLs
- `RAG.Doc.ACL` enumerates the principals allowed to read each document.
  `KnowledgeBase.retrieve(principal=…)` filters out documents the caller
  cannot read before scoring them.
- The default KB includes an `internal-er` document with `acl=["analyst"]`
  to demonstrate that an `anon` principal cannot retrieve it.

## Data retention
- `state.json` is the only persistent artefact. It contains no PII by
  construction (synthetic data only) and is overwritten in place at every
  step.
- The incident log is in-memory and is discarded when the process exits
  unless the caller persists `CopilotRunRecord.incidents`.

## User rights
- Because no real PII is processed, no data-subject rights apply. If the
  harness were re-pointed at real data, the integrator must add explicit
  consent, retention, and deletion controls; this is out of scope here.
