# CP-N1-B — por dónde empezar

Tu archivo es `cp_n1_b.py`, en esta carpeta. Ya tiene las funciones declaradas: escribe el cuerpo
de cada una según `../BRIEF.md`. Si hiciste el You Do
de S08, puedes partir de tu `etl_cp_n1_b.py`.

Verifica con `python3 tests/test_demo.py` desde la raíz del paquete. Las pruebas revisan tu
archivo, no la referencia: al principio fallan todas, y cada fallo dice qué función escribir.

La solución de referencia está en `../reference/cp_n1_b.py`. Léela solo para comparar cuando tus
pruebas pasen.
