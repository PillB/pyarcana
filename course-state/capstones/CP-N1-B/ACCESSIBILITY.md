# Requisitos de accesibilidad

La salida es texto: el manifest es JSON y `demo.py` imprime una línea por fuente con sus
conteos. Si una fuente no cuadra, la corrida imprime `ERROR` seguido de los nombres de las
fuentes.

- La información no se transmite solo por color.
- Los estados se nombran en texto (`ERROR`, `reconcile_ok`).
