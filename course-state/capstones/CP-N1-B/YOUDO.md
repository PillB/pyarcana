# You Do (Haces tú)

Trabajo independiente.

1) Agrega una fuente JSONL además de CSV y JSON. 2) Agrega un test de rerun que compare hashes. 3) Agrega un campo lineage_id a cada fila.

## Criterios de éxito
- El código corre desde un entorno limpio.
- Los tests normal/boundary/failure pasan.
- No hay PII real ni secretos.
- Las limitaciones están documentadas.
